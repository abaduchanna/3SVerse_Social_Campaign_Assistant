# 3SVerse YouTube Campaign Uploader v1.0.0

Schedules one day-matched video/Short per campaign day on the exact **3S Verse** YouTube channel.

- Skips account switching when `3S Verse` is already active.
- Otherwise switches to the exact `3S Verse` account and verifies it in Studio.
- Directly attaches the selected folder video without opening Windows Explorer.
- Fills title, full description, hashtags and extracted video tags.
- Chooses “not made for kids”, advances all three steps, sets the exact date/time, waits for upload/checks, schedules, and waits for confirmation.
- Use **Stop after current upload** for a safe stop.

Install with Chrome `Load unpacked`, selecting this folder. Keep the unpacked folder in place while installed.
