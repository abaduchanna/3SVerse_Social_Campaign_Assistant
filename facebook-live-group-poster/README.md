# 3SVerse Facebook Live Group Poster

Separate Chrome extension for posting one Facebook Live link, text and hashtags to a saved selection of groups joined by the signed-in Facebook account.

## Workflow

1. Load this folder as an unpacked Chrome extension.
2. Click **Import / refresh Your groups**. It opens Facebook **Your groups**, scrolls the complete list and saves exact group URLs.
3. Select only the groups that should receive live-link posts and click **Save group selection**. The choice remains saved after Chrome restarts.
4. Enter the Facebook Live link, post text and hashtags.
5. Click **Start selected-groups campaign**. The extension posts to each selected exact group URL, one at a time, with a 30-second safety delay.

The extension never uses partial group-name search. It stops on the first Facebook error to prevent wrong-group or duplicate posting.
